# Level Up AI examples

Small, practical examples to accompany Level Up AI episodes. Start with a tool and topic:

| Tool | Example | What it shows |
| --- | --- | --- |
| Claude Code | [Status line](claude-code/status-line/) | Model, directory, optional label and coloured context bar |
| OpenAI Codex CLI | [Status line](codex/status-line/) | Built-in model and context indicators |

Each topic directory contains its own instructions and copyable examples. Future episodes can add directories under the relevant tool without changing existing examples.

These examples adapt a working local setup into standalone, generic examples. The context display helps you judge when to compact; it does not predict an exact automatic compaction cutoff. Compact when the task needs it rather than following a hard-coded threshold.

Trying the examples and running the local tests needs no API tokens and makes no paid calls. Using the coding tools themselves requires your usual tool access. Nothing here automatically changes your settings.
